## What is HTML?

HTML stands for **Hypertext Markup Language**.

- The **"Hyper"** means that the text can link/refer to other text.
    
- It is a very simple language that makes use of **tags** to describe objects.

To illustrate this, we will use the metaphor of a fully packaged gift:

- The gift on the outermost of the package is covered with the wrapping paper. If we simply said/or used the tag `<wrapping-paper>`, the computer assumes its infinite, so we need to close it up with a closing tag `</wrapping-paper>`.
    
- Every other "element" of the gift will go into this wrapping paper tags.
    
- Next we have the wrapped box, i.e., `<box> </box>`.
    
- Inside the box, say we have a toy train (`<train> </train>`) made up of smaller unit components: a locomotive along with attached cars. We would structure the train like so, inside `<box>`:

HTML

```html
<box>
    <train>
        <locomotive>
        <car>
        <car>
    </train>
</box>
```

## The Essential Syntax of HTML

- `<tag>` for an **open** tag and `</tag>` for a **closing** tag.
    
- Tags can be **nested**, as we saw in the metaphor.

Even though there are a _lot_ of tags in HTML, there are really only a few you need to focus on as a beginner. You'll learn them in the next class.
