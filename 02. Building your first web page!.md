### Getting Started: The Setup

To build a website, you need a basic foundation of essential tags. Follow these initial setup steps:

* **Step 0 (Code Editor):** You need a code editor to write your code. Popular examples include **VS Code**, **Atom**, or **Zed**.
* **Step 1 (Project Folder):** Create a dedicated folder where you will store everything related to your website.
* **Step 2 (The Homepage):** Create a file named `index.html` and save it. The homepage on a web server must be named `index.html`.
* **Step 3 (Preview):** Open your `index.html` file in any web browser to see your progress.

---

### Essential Rules & Code Structure
Before diving in, keep these critical formatting rules in mind:

* **Lowercase Tags:** Every tag name should be written in lowercase. The *only* exception to this rule is the `<!DOCTYPE html>` tag.
* **Indentation:** Using proper code indentation is not mandatory, but it helps you understand the hierarchical structure of your code and makes it much easier to read and maintain. Just be careful not to overdo it!

Every standard HTML webpage is built using the following core elements:

1. **`<!DOCTYPE html>`**: This tag must be added first. It tells the browser to render the page correctly as an HTML webpage.
2. **`<html>`**: The opening and closing `<html>` tags wrap around everything else on your page. While it might seem redundant, it is absolutely mandatory.
3. **`<head>`**: This section holds extra information (metadata) about the page.
* **`<title>`**: Placed inside the `<head>`, this sets the name of your website as it appears on browser tabs and in Google search results.
* **`<meta>`**: Holds descriptive data and information about your webpage.
4. **`<body>`**: This is where the actual visible content of your webpage is held. To see changes, write your content here and refresh your browser.
> **Note:** The layout below (minus the generic body text) is essentially the basic structure of every single webpage and should be used as your template going forward.

---

### Practice Code
Here is the complete practice code for the website:
```html
<!DOCTYPE html>
<html>
  <head>
    <meta charset="utf-8">
    <title>My First Website</title>
  </head>
  <body>
    My First Website!
  </body>
</html>
```
